# Kotlin

Trilha em 10 aulas sobre a linguagem Kotlin. Kotlin pode compilar para diferentes alvos; APIs de JVM, Java e kotlinx.coroutines são identificadas como específicas, não como regras universais da linguagem.

## Como estudar

1. Leia uma aula por vez.
2. Feche o arquivo e explique em voz alta.
3. Responda as perguntas da aula em perguntas/ antes de abrir as respostas.
4. Marque a aula como concluída quando conseguir explicar sem consultar.
