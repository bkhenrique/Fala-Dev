# Aula 01 — C#, .NET e execução

> **Objetivo:** C# é uma linguagem. .NET é uma plataforma que reúne runtime, bibliotecas, compiladores e ferramentas. São conceitos relacionados, mas não sinônimos.

## Conceito

C# é uma linguagem. .NET é uma plataforma que reúne runtime, bibliotecas, compiladores e ferramentas. São conceitos relacionados, mas não sinônimos.

## Como funciona

No fluxo comum de .NET, o compilador produz CIL e metadados em assemblies. O runtime pode compilar o código intermediário para código nativo durante a execução (JIT); também há opções AOT em alvos suportados. A versão da linguagem e o framework de destino são escolhas separadas.

## Regras e limites

Não presuma que toda implementação de C# use o mesmo runtime nem que toda API exista em qualquer target framework. Documente as versões e alvos escolhidos.

## Como explicar

C# é a linguagem e .NET é uma plataforma. CIL é código intermediário; JIT e AOT são estratégias de compilação com suporte dependente do alvo.

## Resumo

- C# é uma linguagem. .NET é uma plataforma que reúne runtime, bibliotecas, compiladores e ferramentas. São conceitos relacionados, mas não sinônimos.
- Não presuma que toda implementação de C# use o mesmo runtime nem que toda API exista em qualquer target framework. Documente as versões e alvos escolhidos.
- C# é a linguagem e .NET é uma plataforma. CIL é código intermediário; JIT e AOT são estratégias de compilação com suporte dependente do alvo.
