# C#

Trilha em 10 aulas sobre a linguagem C#. C# é a linguagem; .NET reúne runtime, bibliotecas e ferramentas. Recursos e APIs disponíveis dependem da versão da linguagem e do framework de destino.

## Como estudar

1. Leia uma aula por vez.
2. Feche o arquivo e explique em voz alta.
3. Responda as perguntas em perguntas/ antes de revelar as respostas.
4. Marque a aula como concluída ao conseguir explicar sem consultar.
