# PHP

Curso teórico em 10 aulas, com foco em explicar a linguagem e o ecossistema nas entrevistas. A referência de linguagem usa PHP 8.5; recursos recentes são identificados pela versão quando relevante.

## Como estudar

1. Leia **uma aula por vez**, com calma.
2. No fim, feche o arquivo e **explique em voz alta**.
3. Responda as perguntas da aula em [`perguntas/`](perguntas/) antes de abrir as respostas.
4. Marque a aula como concluída quando conseguir explicar sem olhar.
5. Use o [glossário](glossario.md) para revisar termos técnicos antes da entrevista.
