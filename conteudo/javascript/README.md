# JavaScript

Trilha teórica em 10 aulas sobre JavaScript como linguagem. ECMAScript define a linguagem; navegador e Node.js são ambientes que oferecem APIs próprias. A trilha de [Node.js](../node/) cobre o runtime, APIs de sistema, Event Loop e execução no servidor.

## Como estudar

1. Leia **uma aula por vez**.
2. Feche o arquivo e **explique em voz alta**.
3. Responda as perguntas marcadas com a aula em [`perguntas/`](perguntas/) antes de abrir as respostas.
4. Marque a aula como concluída quando conseguir explicar sem olhar.
