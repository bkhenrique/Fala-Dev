# Node.js — perguntas

Perguntas de entrevista separadas por **nível**. Cada uma indica a aula de onde vem e tem a resposta escondida: responda **em voz alta** antes de abrir.

| Nível | Tipo de pergunta | Perguntas |
|---|---|---|
| [Nível 1 — O que é?](nivel-1.md) | Definições. Tem que sair sem pensar. | 26 |
| [Nível 2 — Por quê? Quando usar?](nivel-2.md) | Comparações e motivos. É aqui que aparecem os *trade-offs*. | 25 |
| [Nível 3 — Como você faria?](nivel-3.md) | Cenários reais: juntar vários conceitos e contar como resolveria. | 9 |

Estrutura de resposta: **Definição → Pra que serve → Exemplo real → Trade-off.**

Sugestão: faça o nível 1 logo depois de cada aula e os níveis 2 e 3 como revisão semanal.
