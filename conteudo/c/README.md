# C

Trilha teórica em 10 aulas sobre a linguagem C. Os conceitos seguem os padrões ISO C e os exemplos indicam quando dependem de C11 ou de uma implementação. Um compilador, sistema operacional e biblioteca podem oferecer extensões que não são garantias universais da linguagem.

## Como estudar

1. Leia **uma aula por vez**.
2. Feche o arquivo e **explique em voz alta**.
3. Responda as perguntas marcadas com a aula em [`perguntas/`](perguntas/) antes de abrir as respostas.
4. Marque a aula como concluída quando conseguir explicar sem olhar.
