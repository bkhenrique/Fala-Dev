# Modelo — pergunta

Coloque a pergunta no **nível** certo do `perguntas.md` da trilha e renumere as seguintes.

| Nível | Tipo de pergunta | Exemplo |
|---|---|---|
| **1 — O que é?** | Definição | "O que é o Event Loop?" |
| **2 — Por quê? Quando usar?** | Comparação, motivo, trade-off | "Worker Thread ou fila?" |
| **3 — Como você faria?** | Cenário real, junta vários conceitos | "Como investigaria uma API lenta?" |

A linha `<sub>` aponta para a aula que explica o assunto. A resposta fica dentro do `<details>` e precisa das linhas em branco para o Markdown funcionar.

```markdown
**N. Pergunta aqui?**
<sub>Aula [03 — Título da aula](aulas/03-nome-da-aula.md)</sub>
<details><summary>Ver resposta</summary>

Resposta curta e direta: definição, pra que serve, um exemplo real e o trade-off.

</details>
```
